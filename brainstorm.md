# 1. What are the goals of this project?
To buil a production-ready app that gives amateur athletes a 'hub' of all of their race results in one place, with analysis of their performance across races an over time. This may be for running, triathlon, cycling, swimming, etc. Races currently are ran by different providers so this app should bring all of these results management systems into one place. 


# 2. What are the milestones of functionality that I want?

## MVP
* At least 2 different races from at least 2 different race providers included in the initial dataset. Expect these to require web-scrapers and storing data in a local database but open to engineering ideas.
* Single user
* User to be able to search race results by their name, age, sport, race provider and race name to identify and select results that belong to them.
* Some initial analysis one comparing the user's race results over time.

## V1
* Slick, user-centric user interface
* Database expanded to more race providers and more races from each provider
* More advanced analysis of race results
* Improved search mechanism for the user to find their race results.

## V2
* Multiple users
* User access management - ability to login and save race results to that user so that these persist between user sessions.
* Optimised backend - where data is stored, how it is scraped etc.

## For later
* LLM integration - for advanced analysis and improved finding of race results.
* Social network - ability to search and see race results of other users.
* Cross-analysis - ability to cross-analyse race results between 2 different users.

## Not in scope
* Payment mechanism
